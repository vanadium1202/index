Engineering interpretations applied in this tool

The report leaves five points to engineering judgement. This tool resolves them as follows — change them in the source if your assessment basis differs.

  1. Weld integrity, primary route. The report gives an explicit combination formula only for the alternate route (0.5/0.5). The primary route (hardness + flaw density) is combined here with the same equal weighting: 0.5 × hardness score + 0.5 × flaw density score.
  2. Per-component score. A valve is scored min(body material, age) and a compressor min(OEM blend limit, age), before the overall minimum is taken across all items — consistent with the module's stated principle that the least compatible element limits overall readiness. (An averaging basis would raise scores; it is the less conservative reading.)
  3. Corrosion rate units. Table 16 prints its bands with a "%" symbol while the parameter description defines corrosion in mm/year. The bands are applied here as mm/year, per the description.
  4. Open-ended bands. Corrosion rate below 0.1 mm/yr and capacity utilisation below 87% fall outside the tabulated ranges; both are treated as the best band (score 5).
  5. Band endpoints. Several tables share an endpoint between adjacent bands (e.g. Table 13 lists both "<10" and "10–20"; Table 18 lists both "87–90" and "90–93"). At a shared endpoint the tool assigns the lower, more conservative score — so 10 years scores 4, not 5, and 90% utilisation scores 4, not 5. Tables with explicitly disjoint bands (6, 7, 10, 12) are applied exactly as printed.
  6. API 5L Gr. B. Not listed in Table 4. On the toughness/yield-strength logic of that table it scores 5, and it is scored 5 here — but flagged, because the preliminary screening in Table 22 marks Gr. B as not compatible, most likely on vintage and documentation grounds rather than strength. Confirm against the actual mill certificates before relying on it.
